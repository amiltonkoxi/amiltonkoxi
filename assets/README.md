## &nbsp;`03` &nbsp; Featured Project · FMEAD-FPGA

**FPGA Multi Modal Edge Anomaly Detector**  ·  Nexys 4 DDR  ·  MicroBlaze soft core

A real time edge sensing platform that fuses motion, environmental, acoustic, and thermal signals to detect anomalies directly on reconfigurable hardware. Telemetry and alerts are exposed through a Wi Fi dashboard and on board displays.

<br/>

<div align="center">
  <img src="./assets/fmead-architecture.svg" width="100%" alt="FMEAD-FPGA system architecture"/>
</div>

<br/>

<table>
<tr><td width="60%" valign="top">

**Engineering challenges**

Limited BRAM. Constrained MicroBlaze processing budget. Multi sensor bring up over SPI and I2C. AXI integration between soft core and custom VHDL IPs. Strict real time behavior across parallel sensor streams. Dashboard memory limits on the ESP32 side.

</td><td width="40%" valign="top">

**Stack**

`VHDL` &nbsp; `C` &nbsp; `MicroBlaze`  
`AXI` &nbsp; `SPI` &nbsp; `I2C` &nbsp; `UART`  
`Vivado` &nbsp; `Vitis`

</td></tr>
